# 研雀 · LitFinch v0.17.0

网站本体 · 云端迁移版，发布日期：2026-10-24。

研雀网站继续通过 [papermindapp.com](https://papermindapp.com/welcome) 使用。本版沿用 PaperMind 网站的版本序列，从 v0.16.10 进入 v0.17.0，汇集此后完成的产品入口、账号登录和云端架构更新。云端业务代码已于 2026-10-23 上线，本次补齐版本标记、正式说明和源码包，不再次迁移数据或切换域名。

## 主要更新

- **网站迁至云端托管**：React/FastAPI 运行于 Vercel，文库、账号和运行状态分别保存到 Turso/libSQL；原网址、账号归属和论文编号保留。本地/传统服务器的 SQLite 与磁盘部署方式继续支持。
- **PDF 与图表私有直传**：文件由浏览器直接上传私有 Blob，绕开云函数整包接收的请求体限制；后端核对归属、大小、类型与哈希后入库。上传失败保留已保存的文献信息，并提供重试入口。
- **任务可在重开页面后接续**：论文解读与画像任务写入持久队列，执行租约限制重复运行；网页重开可继续排队任务，已中断任务提供明确重试，不覆盖人工修改的结果。
- **多实例共用运行规则**：AI 次数、并发租约、邀请、服务配置和供应商冷却持久保存，避免不同云函数各自计算额度；账号与设备的数据归属检查保留。
- **产品首页、试读与身份登录**：统一「研雀 · LitFinch」名称；提供免登录试读和样例卡片导出；通过 Zotero 身份登录进入原阅读空间，原匿名空间按既有归属规则继续处理。
- **云端备份与附件维护**：支持导出角色数据库、下载私有附件、哈希校验和新目录恢复；过期附件由受保护的维护入口处理。图表可读取私有存储并进入 PowerPoint/Markdown 导出流程。
- **构建依赖更新**：Vite 升至 8.3.5，修复此前阻断公开 CI 的依赖告警；前端、后端和浏览器回归纳入公开仓库检查。

## 使用与自行部署

日常使用直接打开 [网站](https://papermindapp.com/welcome)，也可先进入 [免登录试读](https://papermindapp.com/demo)。已有用户无需手动搬运论文；迁移后旧会话失效时重新登录即可。

自行部署下载本 Release 的 `litfinch-website-v0.17.0-source.tar.gz`，或检出 `v0.17.0` 标签。环境为 Python 3.12、Node.js 22.13+（22.x）或 Node.js 24 LTS；具体步骤见 [README](https://github.com/lvyrana/papermind-source/blob/v0.17.0/README.md)和 [Vercel 部署说明](https://github.com/lvyrana/papermind-source/blob/v0.17.0/docs/vercel-deployment.md)。源码采用 AGPL-3.0-only，不附服务密钥、数据库、用户论文或原私有开发历史。

部署模板中的生产目标护栏及一次性导入脚本需要按自己的资源核对，不能直接套用维护者的生产目标。预览与生产须使用不同资源；上线前完成账号隔离、文件访问、备份与恢复验证。

## 与 Zotero 插件的关系

网站本体版本为 **v0.17.0**；[研雀 · LitFinch for Zotero](https://github.com/lvyrana/papermind-zotero/releases/tag/v0.7.1)单独使用 **0.7.1**。插件既能在 Zotero PDF 旁使用阅读台，也能把所选论文送入网页版；它不包含在本体源码包中。包内 `zotero-plugin/` 仅是旧自动更新分发镜像，仍保留 0.3.0，本次不切换自动更新。

## 验证与使用边界

- 发布基线已通过隔离后端、真实本地 HTTP、前端测试/构建/lint、依赖审计，以及 PDF 阅读、账号和公共入口三组浏览器回归；发布提交另核对 VERSION、前端元数据和源码清单一致性。
- 迁移验收已完成原账号登录、原记录恢复、真实 AI 请求、私有 PDF 下载、附件哈希核对和一次云端备份恢复。定时任务的配置启用与每次实际运行分别记录。
- 当前生产备份调度在维护者的 Mac 上执行，依赖开机联网；附件清理不替代数据库备份。普通恢复包不含服务密钥、邀请或会话，恢复配置需另行保管。
- AI 调用仍受服务准入、额度和供应商配置约束；免费托管不等于无限文件容量或免费无限模型调用。
- 插件内的卡片、笔记与汇报不会自动同步到网页版。插件实机验收范围为 macOS / Zotero 9.0.6，其他平台不据此承诺兼容。

此版本号用于网站产品发布，既有软著 V0.16.10 冻结材料不随之改写。
